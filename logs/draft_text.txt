[         ] 研究初稿说明：本文以当前已推导的谱兼容包络 R(x,y)、QoS 下界 Q_G(r)、六标量信息类 sharpness 以及退化边界结果为理论主线。正交分解、2×2 PSD/Schur 补、算子范数、矩阵补全、trust-region 与 S-procedure 均视为已有工具，不作为创新。定理 2–3 仍应在正式投稿前进行独立数学复核和进一步公式级查新；本文不宣称“首次提出”。
[Heading1 ] 摘要
[         ] 在离散 RIS 与多用户波束配置的候选验证中，精确的最坏情况 QoS 判定可由单球 S-procedure 或 trust-region 方法完成，但对大量固定候选逐一执行精确验证会带来额外计算成本。常见的廉价解析界通常分别使用完整误差半径来降低期望信号、放大干扰，从而忽略同一 CSI 误差在不同方向之间共享球预算以及方向增益来自同一干扰算子的谱兼容性。本文从固定配置的鲁棒 QoS 裕量出发，仅保留六个标量几何摘要：期望方向功率、标称期望幅度、标称干扰幅度、期望方向干扰增益、正交子空间干扰增益以及整体干扰算子谱范数。首先求解由这三个谱量共同约束的误差方向极值，得到一个连续三段闭式的谱兼容干扰包络 R(x,y)。在此基础上构造共享误差预算 QoS 下界 Q_G(r)，并证明其不劣于未利用谱兼容性的旧包络。进一步，在非退化非正交条件下，本文给出六标量信息类上的 sharpness 构造，即 Q_G 等于所有兼容实例真实最坏 QoS 的下确界；对 β₀=α 的退化边界，额外的相位兼容关系导致另一套边界包络。本文同时讨论六标量信息不足引起的边界跳变及加入信道范数信息的潜在增强。数值部分仅采用轻量验证：闭式极值核对、谱参数扫描和一个小型固定候选池认证实验，不引入动态轨迹、学习算法或重型联合优化。
[         ] 关键词：鲁棒 QoS 认证；共享误差预算；谱兼容；信息受限最优包络；RIS；固定配置
[Heading1 ] 1 引言
[         ] 可重构智能表面（RIS）和多基站联合波束控制使无线网络中的完整配置同时包含离散相位状态与多流波束。对一个已经生成的候选配置，部署前首先需要判断其在有界 CSI 不确定性下是否满足所有用户的 QoS 约束。精确固定配置验证本质上是球约束不定二次问题，可以借助 S-procedure、半定规划或 trust-region 方法求解；因此，本文并不把“鲁棒 RIS”“无 SDP”“正交分解”或“低秩求解”本身作为创新。
[         ] 本文关注一个更窄但可独立刻画的问题：当控制器不希望为每个候选保留完整矩阵几何，只使用少量可预计算的谱摘要时，能够得到多强的统一安全 QoS 保证？一个直接的廉价界会把完整误差半径同时用于期望信号下降和干扰增长，但这相当于让同一个误差预算被重复使用。已有共享预算包络通过把误差分解到期望方向和其正交补来缓解这一保守性，但若只分别使用 ||Cᴴv||、||CᴴP||₂ 和 ||C||₂，仍然没有充分利用这三个量来自同一个算子 C 的事实。
[         ] 本文的理论主线因此是“谱兼容性”。我们先解决一个算子极值：固定期望方向增益 α、正交子空间增益 β 和整体谱范数 β₀ 时，平行误差幅度 x 与正交误差预算 y 能在干扰输出端产生的最大联合幅度是多少？该问题可由二维压缩 Gram 矩阵的半正定约束化为一个一维极值，并得到三段闭式 R(x,y)。随后将其嵌入鲁棒 QoS 裕量，得到 Q_G(r)。更重要的是，本文不止证明 Q_G 是安全下界，还尝试回答“只知道这六个标量时是否还能系统地提高这个统一保证”，并在明确维度和非退化条件下给出 sharpness 构造。
[         ] 本文与运行期配置复用管理的关系是前后衔接而非重复：本篇研究部署前固定候选的鲁棒认证几何；若某一候选最终被选中，可再计算其完整配置特定鲁棒半径，用于后续的在线保留/刷新管理。因此，本篇的主要价值应由新的极值结构、精确性与信息类 sharpness 来支撑，而不是依赖动态触发实验。
[         ] 本文拟形成的一条主贡献及三个理论性质如下：
[         ] • 提出谱兼容共享误差预算包络。对固定谱摘要 (α,β,β₀)，显式求解平行/正交误差在同一球预算下的最大干扰输出，得到连续三段闭式 R(x,y)，并由此构造安全 QoS 下界 Q_G(r)。
[         ] • 证明 Q_G 不劣于未利用三个谱量共同兼容性的旧共享预算包络，并给出发生严格改善乃至“unknown→certified feasible”翻转的参数区间与数值实例。
[         ] • 在非退化的六标量信息类 S₆ 上构造可逼近 Q_G 的兼容实例，从而得到信息类 sharpness；对 β₀=α 的退化边界单独刻画相位兼容性并给出边界包络。
[         ] • 给出轻量的安全数值实现和候选认证接口。数值实现只用于保证下界计算与验证，不把区间划分、trust-region 回退或候选排序本身列为创新。
[Heading1 ] 2 系统模型与固定配置鲁棒 QoS
[Heading2 ] 2.1 固定候选配置
[         ] 考虑一个共享 RIS 辅助的多小区下行系统。离散 RIS 状态与各基站波束在候选生成阶段已经固定。对用户 u，将所有有效基站信道堆叠为 ĥ_u∈C^n，将目标流联合波束记为 b_u，将其他流波束组成干扰矩阵 C_u=[b_v]_{v≠u}。在固定候选验证阶段，不再优化 RIS 相位或波束，只判断该候选在给定不确定球内是否安全。
[         ] h_u = ĥ_u + e_u,    ||e_u||₂ ≤ r_u.    (1)
[         ] 用户 u 的最坏 QoS 裕量定义为
[         ] q*_u(r_u) = min_{||e_u||≤r_u} {|b_uᴴ(ĥ_u+e_u)|² − γ_u||C_uᴴ(ĥ_u+e_u)||² − γ_uσ_u²}.    (2)
[         ] 若对所有用户 q*_u(r_u)≥0，则该固定候选在给定球集下鲁棒可行。式(2)是标准的球约束二次问题，其精确求解可用 trust-region 或单球 S-procedure 完成；本文使用精确方法作为参考判定与 unknown 回退，而不是把它们列为贡献。
[Heading2 ] 2.2 六标量信息类
[         ] 为简化记号，以下省略用户下标。设 b≠0，定义 v=b/||b|| 和 P=I−vvᴴ。本文保留以下六个标量：
[         ] p=||b||²,   a=|vᴴĥ|,   I₀=||Cᴴĥ||,   α=||Cᴴv||,   β=||CᴴP||₂,   β₀=||C||₂.    (3)
[         ] 它们分别表征期望流功率、标称期望幅度、标称干扰幅度、期望方向上的干扰增益、正交子空间最大干扰增益以及整体干扰算子谱范数。固定这六个标量的所有兼容实例构成信息类 S₆。除非额外说明，S₆ 不固定 ||ĥ||、C 的秩、具体基站零填充支撑或 RIS 传播可达集合。因此后文“sharp”只指 S₆ 上的统一下界，而不是实际 RIS 可达集合上的全局最优。
[         ] 三个谱量并非独立，必须满足
[         ] max{α,β} ≤ β₀ ≤ √(α²+β²).    (4)
[Heading1 ] 3 谱兼容误差幅度包络
[Heading2 ] 3.1 方向分解与旧包络
[         ] 将一个真实误差写成 e=tv+w，其中 vᴴw=0。令 x=|t|，并记 y 为正交误差范数上界。对于半径为 r 的球，有 x²+y²≤r²；在最坏情况搜索中可取 y=√(r²−x²)。旧共享预算包络分别利用
[         ] ||Cᴴe|| ≤ β₀√(x²+y²),    ||Cᴴe|| ≤ αx + βy,    (5)
[         ] 并取两者的最小值。它已经保留了球预算共享，但仍把 α、β、β₀ 当作相互独立的界。实际上这三个量来自同一算子 C，因此允许的交叉项受到更强的谱兼容约束。
[Heading2 ] 3.2 三段谱兼容闭式
[         ] 令 d=Cᴴv。对任意 u⊥v、||u||≤1，记 ℓ=Cᴴu 和 s=||ℓ||≤β。因为 [v,u] 是收缩映射，二维输出 Gram 矩阵满足
[         ] [[α², dᴴℓ],[ℓᴴd, s²]] ⪯ β₀² I.    (6)
[         ] 由 Cauchy–Schwarz 与式(6)的行列式条件可得
[         ] |dᴴℓ| ≤ min{αs,  δ√(β₀²−s²)},    δ=√(β₀²−α²).    (7)
[         ] 因此，固定 x 与 y 时的最大扰动输出幅度可化为一维极值
[         ] R²(x,y)=max_{0≤s≤β}{α²x²+s²y²+2xy·min[αs,δ√(β₀²−s²)]}.    (8)
[         ] 进一步令 ν=√(β₀²−β²)，可得到以下候选闭式。
[         ] 定理 1（谱兼容方向包络）：若 (α,β,β₀) 满足式(4)，则对任意 x,y≥0，式(8)的最优值由以下连续三段函数给出；对任意 e=tv+w、vᴴw=0、|t|=x、||w||≤y，有 ||Cᴴe||≤R(x,y)。
[         ] R(x,y) = { √(α²x²+β²y²+2δνxy),          δx≤νy;
[         ]               β₀√(x²+y²),                    νy<δx<αy;
[         ]               αx+δy,                         δx≥αy. }    (9)
[         ] 证明思路：在 s∈[0,δ] 上两类交叉项的较小者为 αs，极值取于端点；在 s∈[δ,β] 上令 k=√(β₀²−s²)，目标成为关于 k 的凹二次函数，其无约束最优点为 δx/y，再投影到 [ν,α]，得到三段条件。端点处各分支连续。该推导只使用经典 PSD/Schur 补和算子范数约束，创新若成立，应归因于所解的具体极值及其在 QoS 认证中的 sharpness，而非这些基础工具。
[         ] 由式(9)立即有
[         ] R(x,y) ≤ min{β₀√(x²+y²), αx+βy}.    (10)
[         ] 当 α=0 或 β₀²=α²+β² 时，新包络会退化到旧包络的相应分支，因此改善不可能处处严格。
[Heading1 ] 4 鲁棒 QoS 包络及信息类 sharpness
[Heading2 ] 4.1 安全 QoS 下界
[         ] 对固定投影模长 x=|vᴴe|，信号项满足 |vᴴ(ĥ+e)|≥|a−x|。令 y=√(r²−x²)，由定理 1 得到
[         ] Q_G(r)=min_{0≤x≤r}{p(a−x)² − γ[I₀+R(x,√(r²−x²))]² − γσ²}.    (11)
[         ] 命题 1（安全性与支配）：对任意固定配置和半径 r，Q_G(r)≤q*(r)。同时，若 Q(r) 表示仅使用 min{β₀r, αx+β√(r²−x²)} 的旧共享预算包络，则 Q(r)≤Q_G(r)。因此 Q_G>0 可以安全确认该用户在半径 r 内满足 QoS；Q_G≤0 只能返回 unknown，不能据此判定不可行。
[         ] 证明直接来自式(10)、真实误差的球预算以及信号幅度的反三角不等式。值得强调的是，Q_G 的作用是廉价“接受”证书，而不是一个双向分类器。
[Heading2 ] 4.2 非正交六标量信息类上的 sharpness
[         ] 仅证明 Q_G≤q* 仍可能被解释为更紧的经验解析界。更强的问题是：如果算法只允许使用式(3)的六个标量，是否存在另一个统一安全函数 L(p,a,I₀,α,β,β₀,r) 在所有兼容实例上都严格高于 Q_G？以下候选定理给出否定答案。
[         ] 定理 2（非退化六标量信息类 sharpness，候选）：设 n≥5、m≥3、β>0、β₀>α，且六标量满足式(4)，p>0、γ>0。则对信息类 S₆，有 inf_{(b,ĥ,C)∈S₆} q*(r)=Q_G(r)。换言之，若某个下界仅依赖相同六标量并要求对 S₆ 全部实例都安全，则它不能在任意参数点系统性高于 Q_G。维度条件目前仅为构造证明的充分条件，不声称最小。
[         ] 构造思路如下。对 Q_G 的最优 x 和 y，先在二维输出平面构造 d 与 ℓ，使 ||d||=α 且 xd+yℓ 的幅度逼近 R(x,y)。为同时精确匹配 β 与 β₀，对 ℓ 作轻微收缩后，在输出空间补充额外方向，通过正半定矩阵插值构造 T，使 ||T||=β²、||ddᴴ+T||=β₀²，且 T−ℓℓᴴ⪰0。取因子 K 使 KKᴴ=T−ℓℓᴴ，再令 B=[ℓ,K]、Cᴴ=[d,B]。最后利用 B 的满行秩构造 ĥ，使 Cᴴĥ 与最坏误差输出同向，从而让三角上界同时逼近等号。
[         ] 该 sharpness 是“信息类 sharpness”，不是“实际 RIS 系统的全局最优”。其一般思想与 optimal recovery / information-based complexity 中的 fiber worst-case 原理一致；本文若有新意，只能是对当前六标量 QoS 极值的显式求值和兼容实例构造。
[Heading2 ] 4.3 退化边界 β₀=α
[         ] 定理 2 的构造依赖 β₀>α。若 β₀=α>0，期望方向 v 已达到 C 的最大谱增益，必有 dᴴB=0。这使标称期望信号与平行干扰分量共享同一个复投影相位，不能像一般分支那样独立实现“信号向下、同方向干扰向上”。
[         ] 设 s=vᴴĥ，I₀=||Cᴴĥ||，并定义
[         ] J=√(I₀²−α²a²),    c=p−γα².    (12)
[         ] 定理 3（退化边界包络，候选）：在 β₀=α>0 的兼容信息类上，若 β>0，则边界统一最优包络可写为 Q_∂(r)=min_{0≤x≤r}{cF_c(a,x)−γ[J+β√(r²−x²)]²−γσ²}，其中 c≥0 时 F_c=(a−x)²，c<0 时 F_c=(a+x)²。β=0 时令 J=0，同式退化为纯平行问题。
[         ] 该边界结果说明：完整的六标量 sharpness 不能只给出一个非退化公式，必须显式分类 β₀>α 与 β₀=α。这里的 dᴴB=0 是标准最大奇异向量等号条件；问题特定的内容在于由这一结构得到的 QoS 相位耦合和边界极值。
[Heading1 ] 5 信息缺失、边界跳变与可选七标量扩展
[         ] 六标量信息类刻意忽略 ||ĥ||。这使某些非退化参数序列可以通过让 ||ĥ||→∞ 来逼近更差的 QoS，从而导致信息类最优值在 β₀→α⁺ 时与 β₀=α 的边界值出现跳变。该跳变不是固定物理系统 QoS 的不连续，而是“只保留六个标量”这一信息压缩的代价。
[         ] 若进一步提供 H=||ĥ||，可推导必要的相位兼容条件
[         ] |dᴴz−α²s| ≤ α√(β₀²−α²)√(H²−a²),    z=Cᴴĥ.    (13)
[         ] 式(13)能够排除依赖无界信道范数的极端兼容实例，但目前尚未得到固定 H 后的完整最优包络。因此本文把七标量扩展作为理论后续问题，而不把未完成的结果列为当前贡献。若后续能得到显式 Q_H(r) 并证明 Q_G≤Q_H≤q*，则可以进一步解释“增加一项物理信息能换来多少认证能力”。
[Heading1 ] 6 安全数值实现与候选认证接口
[Heading2 ] 6.1 一维最小化的安全下界
[         ] 式(11)只剩一个标量 x，但直接网格采样再取最小值会给连续最小值的上估计，可能导致误接受。因此实现时仍需要区间下界。令 x=r sinθ、y=r cosθ，θ∈[0,π/2]。R 对 (x,y) 的变化可由 α|Δx|+β|Δy| 控制。对宽度 Δθ 的区间，以中点 θ_m 计算
[         ] R_U=min{β₀r, R(r sinθ_m,r cosθ_m)+r(α+β)Δθ/2}.    (14)
[         ] 信号项使用 a 到该区间 [r sinθ_lo,r sinθ_hi] 的距离平方作为下界，再减去 γ(I₀+R_U)² 和噪声项。所有区间下界的最小值即为 Q_G 的安全数值下界。在精确实数算术中可保持安全性；若要宣称机器级严格证书，还需要定向舍入或区间算术，普通浮点容差只能作为工程保护。
[Heading2 ] 6.2 候选池中的使用方式
[         ] 对于每个候选和每个用户，先计算六标量并评估 Q_G 的安全区间下界。若所有用户均大于正裕量 τ，则直接接受该候选；否则返回 unknown 并调用精确信赖域/S-procedure 参考求解。Q_G<0 不构成安全拒绝。最终候选的排序目标可以是预先定义的功耗或其它部署成本，但排序本身不是本文创新。若后续运行期管理需要完整鲁棒半径，应只对最终选中配置再计算 ε_val，而不能把指定半径下的 Q_G>0 当成最大半径证书。
[         ] 预计算 α、β、β₀ 需要小矩阵谱范数，随后的一维区间评价只依赖标量运算。本文不预设其一定快于最优实现的低秩 trust-region；实际计算价值由第 7 节的轻量实验直接测量。
[Heading1 ] 7 轻量数值验证设计
[         ] 本文理论主线已经较强，因此实验不需要重新搭建动态多小区系统，也不需要移动轨迹、延迟、学习算法、硬件联调或大规模参数扫描。正式稿建议控制在“2 图 + 1 表”，只回答三个问题：闭式是否正确、Q_G 是否在典型谱区域明显优于旧 Q、以及放入一个小型固定候选池后是否减少精确回退。

[Heading2 ] 7.1 可直接沿用的初步诊断结果
[         ] 当前研究备忘录中的实现诊断已经给出三个可作为“代码自检”而非正式性能结论的结果：一是 100 组方向极值参数的闭式与密集标量参考一致，60 组补全构造的六标量最大偏差约 2.44×10⁻¹⁵；二是在一个非正交例子 p=4、a=1.3、I₀=0.5、α=β=1、β₀=1.1、γ=1、σ²=1.5、r=0.5 中，旧 Q≈−0.024569，而 Q_G≈0.034624，精确信赖域参考同样约为 0.034624，出现从无法认证到可认证的符号翻转；三是这些有限样本只能用于发现推导或实现错误，不能替代理论证明和正式统计实验。

[Heading1 ] 8 与配置生命周期管理工作的关系
[         ] 本篇和后续配置复用管理可以组成统一的“配置生命周期可信管理”主线，但二者的研究问题应保持分离。部署前，本篇对一批固定候选在给定误差半径下做低成本安全认证；若候选被选中，再对最终配置计算完整的配置特定鲁棒半径 ε_val。部署后，运行期控制器利用参考相对信道漂移与 ε_val 判断当前完整 BS/RIS 状态是否继续保留或需要刷新。
[         ] 候选生成 → Q_G 指定半径认证 → 最终 ε_val → 配置部署 → 在线 retain / refresh.    (15)

[Heading1 ] 9 讨论与局限
[         ] 第一，本文的 sharpness 是针对 S₆ 这一抽象信息类。某些达到或逼近 Q_G 的极端实例可能不满足具体 RIS 信道几何、固定基站波束支撑或现实信道范数，因此不能把 S₆ sharpness 解释为“真实 RIS 系统所有可用信息下的最优证书”。第二，底层数学工具——二维 PSD、Schur 补、算子范数、最大奇异向量等号条件和矩阵补全——均已有成熟理论。本文真正需要查新的，是固定 (α,β,β₀) 下线性组合幅度极值的三段闭式、将其嵌入 robust-QoS 后的 S₆ sharpness，以及 β₀=α 的边界分类是否已有等价 operator-extremal 结果。
[         ] 第三，Q_G 只是一侧接受证书。若 Q_G≤0，配置仍可能鲁棒可行，必须回退到精确参考；因此方法价值取决于实际候选池的接受率和回退成本。第四，当前七标量扩展只得到必要相位约束，尚未闭合。第五，本文不声称解决候选生成、配置安装延迟、CSI 统计覆盖或完整实时部署问题。
[Heading1 ] 10 结论
[         ] 本文围绕固定波束/RIS候选配置的鲁棒 QoS 认证，研究在只保留有限谱摘要时能够获得多强的统一安全保证。通过联合使用期望方向增益 α、正交子空间增益 β 和整体谱范数 β₀ 的兼容关系，本文将共享误差预算下的干扰方向极值显式化为三段闭式 R(x,y)，并据此构造 QoS 下界 Q_G(r)。在非退化条件下，候选 sharpness 结果表明 Q_G 可达到六标量信息类的统一最优下确界；在 β₀=α 的退化边界，额外相位兼容关系导致不同的最优包络。该框架的理论意义不在于使用新的基础不等式，而在于对一个具体信息受限鲁棒 QoS 极值问题给出显式结构、sharpness 与边界分类。后续工作首先应完成独立数学复核和最后一轮 operator-interpolation / contraction-completion 公式级查新，其次只需用轻量数值实验验证闭式、边界与实际候选认证收益。
