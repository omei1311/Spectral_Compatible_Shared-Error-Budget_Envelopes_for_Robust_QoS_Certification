# V6.5 理论与数据核查

## 范围
保留 V6.4 与原始数据。主定理、包络定义与历史池未更改。V6.5 修正新增紧凑求解器和接口实验，结果位于 results_v65/。

## 求解器
新增 v65_clients.py；不将任何非零谱权重阈值化为零。维护可行上乘子，用对偶下值和谱坐标可行点上值控制目标误差；决策分别使用下值接受、上值拒绝，否则 unresolved。浮点保护量不是严格外向舍入证明，谱分解本身仍有误差。
八维三干扰列近 hard case 反例已加入。球内见证值 −5.6333e−7，V6.4 错误正值约 1e−7；V6.5 正确拒绝。另含精确零权重、微小非零权重、PSD 内点、奇异、hard 等号、重根和 r=0。
共 877 条检查，其中池内查询 864 条；与旧参考最大差 1.938e-12。数值一致性不替代解析证明。

## 计时与构建
所有 48 用户各执行 N 次，N=1/10/100；计数断言为48N，五次交错重复并预热，实际分母写入 CSV。
100 次批次摊销：六标量 44.24 µs，七标量 0.25 µs，紧凑 TR 547.30 µs。V6.4 的0.9/25 µs错误数字完全撤回。
构建分别计时：六标量 0.0459 ms/用户，七标量 0.0469，紧凑 0.0254。当前六标量公共构建器额外形成 A/g，不宣称为最优构建成本。
载荷48/56/144B按float64统计，不是Python对象内存；共同外部参数不计。删除旧约1.7KB估算基线，不将其视为精确查询必要存储。
