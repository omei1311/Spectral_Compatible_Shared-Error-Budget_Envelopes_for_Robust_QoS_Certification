## 三、自适应区间细化（64→256→1024→4096）

- **接受数与固定 J=4096 完全一致**（探索批 390=390=390；断言通过，
  且嵌套网格下区间下界单调保证这一点）；cannot_cross 停止规则有舍入
  裕量保护（可行中点值 < τ − 1e-9·scale 时细化不可能越过阈值）。
- 算术量节省：单元评估次数 176768 对固定-256 的 686592（**3.9×**）。
- **但墙钟时间更慢**（1.45× 对 1.69×）：多层 J 的 Python 循环与中点
  目标求值开销超过向量化大网格的节省。结论：自适应细化在本规模是
  算术节省器，不是时间节省器；不进入选定流程，保留为可配置选项。

## 六、结论与限定

**成立**：联合认证有真实但适中的互补收益（相对 L_quad +16/1080 与
+1/540 单元）；L_quad→Q_G→容差参考是本任务/本池/本实现下的最优分级
（约 2×，参考调用省约 53%）；筛选优势随维度增大（S 持平 → L 3.5×）；
自适应细化省 3.9× 算术但不省墙钟。

**不成立/需限定**：Q_G 不是速度来源（单独 1.5–1.7×，慢于 L_quad 级）；
D 级应删除；自适应不入选；所有时间结论限定于本候选池、规模与 Python
实现，逐对加速比与中位数之比已分开报告（L_quad→Q_G 确认批 2.01×
中位对 2.02× 中位数之比，11/15 逐对获胜）；确认批 5 个种子共享协议、
多半径多阈值同信道相关，不作独立样本推断。

**贡献归属**：理论贡献（谱兼容极值、信息类最优性、边界分类）不变；
本轮新增的是**工程组合收益**（联合 max 与分级顺序）与**实现优化收益**
（容差参考、共享缓存），三者已在报告中分开陈述。
