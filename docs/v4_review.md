## 1 定理2中错误的 PSD 顺序

文中将 ell 缩为 ell_epsilon=(1-epsilon)ell 后声称 G_epsilon ⪯ G。设 d^H ell=delta k，则

G-G_epsilon = [[0, epsilon delta k], [epsilon delta k, (2epsilon-epsilon²)||ell||²]]。

其行列式为 −epsilon² delta² k²；交叉项非零时是负数，因此差矩阵不是 PSD。用现有构造 alpha=beta=1、beta0=1.1、x=0.45、y=0.1、epsilon=0.01 得特征值约 −0.00294697 与 +0.00712597。这个问题是证明写法错误，不是已经发现定理2结论的反例。

可用的替代论证是输出空间不等式（0<epsilon<1）：

dd^H + ell_epsilon ell_epsilon^H ⪯ dd^H + ell ell^H ⪯ beta0² I。

后一个不等式由 [d,ell]^H[d,ell] ⪯ beta0²I 及非零奇异值对应得到；前一个是同一个秩一矩阵的正系数缩放。新增第三个输出方向 beta²≤beta0²，仍保持括号下端可行。不要把这两个不同空间中的矩阵误写成同一个 PSD 顺序。

还需明确以下条件与证明：

- 当前 ell 表达式除以 alpha，但定理允许 alpha=0。主构造可先限制 alpha>0，随后单独处理 alpha=0；此时 beta0=beta，取 C^H=[0,beta]、h=(a,I0/beta)、b=sqrt(p)e1，配合平行抵消与正交放大即可构造达界实例（再零填充）。
- epsilon 应为 0<epsilon<1，不是“任意 epsilon>0”；r=0、y*=0 等端点不得直接代入含 y* 分母或 u/||u|| 的表达式。
- 求 t 时应针对二维平面块 F(t)=lambda_max(dd^H+(1-t)ell_epsilon ell_epsilon^H+t beta²I2)，而非仅对附加 beta² 的三维最大特征值。beta=beta0 时，三维最大值可在一段 t 区间恒为 beta0²，单凭 f(0)=0 不能推出 t*>0。
- 对 alpha>0、beta0>alpha、0<epsilon<1，二维 F(0)<beta0²：若缩放后仍取等号，对应最大特征向量必须与 ell 正交，则其特征值只能来自 dd^H，至多 alpha²，矛盾。F(1)=alpha²+beta²≥beta0²，故介值定理给出某个 t*∈(0,1]。
- t*>0 且 ||ell_epsilon||<beta 时，二维剩余块 t*(beta²I2−ell_epsilon ell_epsilon^H) 正定，第三方向为 beta²>0，因此 K 可逆、B满行秩。这给出了可以进一步写成严格引理的路线，而非只能诉诸 generic 数值观察。
- 存在性证明不需要显式根或唯一根。可以用连续性与介值定理；不要把“代码用二分”本身当作证明未闭合的理由。应核实 n≥5,m≥3 下通过零填充保持所有摘要。

A2 的9例仅核对 alpha,beta,beta0三个谱量；六标量的完整复原属于另一个A3构造步骤。第4.2证明状态与第7.1应分别交代，避免合并成9例完整sharpness验证。

## 2 命题1证明与符号

第4.1正文先给出 abs(v^H(h+e))≥abs(a-x)，这是正确的；证明随后改为 ≥a-x 并直接平方。当 x>a 时，这个较弱负数下界不能平方。应始终写

abs(b^H(h+e))≥sqrt(p)·abs(a-x)，从而 abs(b^H(h+e))²≥p(a-x)²。

式(11)不必改变，这里是证明链条的修正。定理1中严格凹二次与 k*=delta x/y 的推导限定 y>0，y=0单独写 R=alpha x；同理将全零谱等端点按连续退化处理。

符号最好分开：用 c_q=h^HAh−gamma sigma² 表示二次目标常数，用 c_parallel=p−gamma alpha² 表示边界系数；正交标称干扰 J 与区间数 J 也应改用不同符号，例如 J_perp 与 N_theta。

## 3 定理3可以补直接构造

边界相容条件应明示：0<alpha=beta0、0<beta≤alpha、a≥0、I0≥alpha a，且信息类非空；beta>0要求有至少一个正交输入和输出方向。令 J_perp=sqrt(I0²-alpha²a²)，取

C^H=[[alpha,0],[0,beta]]，h=(a,J_perp/beta)^T，b=sqrt(p)e1。

这个实例精确匹配全部六标量。对任意 x∈[0,r]，取 y=sqrt(r²-x²)，当 c_parallel≥0取 e=(-x,y)^T；当 c_parallel<0取 e=(x,y)^T。信号—平行干扰项分别为 c_parallel(a−x)² 或 c_parallel(a+x)²，正交干扰项恰为 −gamma(J_perp+beta y)²。再取边界一维目标的最小点，就使安全下界达界。更高固定维度通过零填充，beta=0及r=0单独处理。

建议将安全性与这个达界构造写为两段严格证明，经独立复核后再决定是否将定理3从候选升级。不要继续用四个数值例子作为一般构造未完成的唯一解释。

第4.3的“上界方向（Q_partial≤q*）”应改称下界安全性方向。同一边界摘要下，通用 Q_G 与 Q_partial均有定义，二者完全可以比较；禁止的是把边界专用公式用于 beta0>alpha 的实例。“不得比较大小”应删除。特别是本文0.59与−0.21恰好就是合法的同边界摘要比较。

摘要仍有“候选构造……即Q_G等于下确界”的确定式措辞，结论也将未闭合sharpness作为得到的结果。若定理2仍未证明，统一改为“提出并验证候选sharpness构造，完整证明待完成”。理论安全性可以由命题证明，数值侧只说未观测到违反，二者不矛盾。

本次额外核查原始720个问题：633个问题的L_quad高于一个实际求值的Q_G目标上估计（tol=1e-9）。例如seed=11、candidate=0、user=0、rho=0.01：

L_quad=0.198195750531；Q_G目标在x=0.009144153241、y=0.002739768498处取0.196451952840。

因为理论Q_G是该目标的最小值，Q_G≤0.196451952840<L_quad，形成具体反向见证；B族另有Q_G>L_quad的实例。因此可以保留无支配结论，但应以这两个方向的实例支持，而不是仅引用区间下界计数。633/720也不是此前635/720的实施界口径，不能混用。
