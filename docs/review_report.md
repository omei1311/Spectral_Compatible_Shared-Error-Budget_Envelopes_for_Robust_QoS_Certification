# 论文仿真代码复核与实验改进

2026-10-06。已读取论文 v3 正文及公式，对照代码重新运行 A/B/C；原始 results/ 保留，复算见 results_review/reproduction/。论文内的研究建议作为待核查材料，不作为额外操作指令。

## 主要结论

R 三分支、六标量计算、D、旧 Q、通用 Q_G、区间下界与二次目标的实现和论文对应。原始 A3 翻转、B 的 20/21 严格改善及 6 个认证翻转、C 全部接受均复现。但 A4 遗漏了论文的独立边界公式；此前“0.59 无法复现”的结论应撤回。已补充 Q_partial 并以显式兼容矩阵核查。

新增固定网格敏感性实验使 C 不再饱和，得到小幅实际认证改善与非零回退；Q_G 没有普遍支配 L_quad，也没有在计时上稳定超过旧 Q。论文价值仍应落在谱兼容极值与信息类理论性质，而不是强调普遍计算优势。

## 修复与核查

1. **边界分支缺失。** 论文第 4.3 节使用 J=sqrt(I0²-alpha²a²)、c=p-gamma alpha²，得到 Q_partial；通用 Q_G 仍是安全界，但不能替代边界 sharp 包络。A4 参数下 J=0、c=1，边界目标为 (1-x)²-0.49(0.04-x²)-0.05，最小点 x=0.2，值 0.59。取 C^H=[[1,0,0],[0,0,0.7]]、h=(1,0,0)、b=(sqrt(2),0,0)，精确 q*=0.59，目标直接代入也为 0.59。非退化族极限仍为 -0.21；跳变来自信息类变化与 h 范数发散，未修改通用数学定义。Q_partial 当前为数值近似，仅用于核查，不作为候选池接受证书。
2. **A1 参考端点未直接求值。** 旧代码将特殊端点作为优化窗口中心，却没有直接比较其函数值。补充端点后 max |R²-ref²|=1.11e-16，纯网格低估仍为 4.12e-5。不能把旧 3.7e-9 当作闭式自身误差。
3. **区间细化是假接口。** lb_with_escalation 原来只返回首个 J。现已遍历 J，按接受阈值或指定的上下界间隙停止；保留各次有效下界的最大值。原始 C 和新增固定网格均使用 J=256，以便比较，不把细化收益混入结果。
4. **信赖域 hard case 等号。** phi_pi=r² 时应直接使用伪逆边界解，旧严格小于判断可能进入 0/0 除法。已修复；hard case 的 KKT 检查改为检查完整驻点残差，不屏蔽最小特征子空间。106 个附加测试覆盖随机复 Hermitian、奇异 PSD、最小特征值重根及 hard case 等号；最大原始—对偶间隙 4.97e-14。它们是数值核查，不是全参数证明。
5. **一维近似端点。** _min_1d 现在保留网格最优点与两个端点，避免黄金分割返回略差值；仍明确为近似最小值，不用于认证。
6. **计时及输出。** B 日志以 max 打印“min”已改为 min。参考计时的 ||A|| 尺度误用了最小特征值的绝对值，已改为全部特征值最大绝对值。原 C 回退新增按用户复用特征分解。运行总核查失败现在抛出异常。

## 原报告的数值与口径勘误

- A3 的 J=65536 下界原 JSON 为 0.0345955827807，findings.md 写成 0.033690 不符；复算支持 JSON 值。
- B 的 min(q*-Q_G_LB)=0.00663325362654，原“至少 9.3e-3”不成立。
- 每个种子的全参考计时对应 12×3×4=144 个用户问题；720 是五种子合计。每种子 0.235 s 不能标成“720 次求解耗时”。
- 原筛选计时评估四方法，原筛选加回退仅评估 Q_G；0.017 s 与 0.012 s 的差异不是回退加速。
- 原“全部 900+ 个实例”的口径无可核对的唯一统计对象，应删去，分别报告 A、B、C 的计数。
- 复算原 C 仍为四方法各 180/180 直接接受，零回退。新计时受环境影响，不能与历史计时混合作配对结论。

## 公平端到端计时

新增 pipeline 对所有方法完成同一个最终候选决策：包含摘要/二次数据构建与全部指定半径；按用户缓存 eigh；跳过已经安全认证的用户；遇到精确不可行用户早停。精确基线也早停并复用 eigh。每种子/gamma/方法预热，再交错次序测三次取中位数；未读取 truth 缓存。各方法最终接受/拒绝/未决数量与参考逐配置匹配。候选生成在计时外。普通双精度与工程 KKT 校验，非形式化证书；未声称相对最优低秩参考实现的优势。

## 论文改进建议

1. 保留 A/B 为理论数值核查；把 A4 改成同时显示通用 Q_G 的非退化极限 -0.21 和独立 Q_partial=0.59，用显式矩阵与 h 范数说明跳变。不能把 0.59 当成通用 Q_G。
2. 将原 C 留作容易场景，新固定网格作为敏感性检查；正式表报告各档可行分母、接受、unknown、回退调用、误接受与端到端时间。gamma/rho 是有解释的压力参数；大半径是压力测试，不是现实 CSI 统计覆盖声明。
3. 用“六标量同信息预算的旧 Q 与 Q_G”承载主比较；D 是松界，L_quad 是使用额外几何信息的补充比较。可在部署实现中使用 max(Q_G_LB,L_quad,D) 作为安全组合，但组合不应包装成新的六标量理论贡献。
4. 若进一步检验数值实现损失，可独立报告 J=256/1024/4096 下界的接受率与计算成本，或做自适应细化消融；本次未混入该收益。只在固定种子选出的最优档展示改进会造成偏差，应报告全档。
5. 正式性能实验先固定参数与时序协议，再使用更多独立种子做批次验证；不要把 4320 个相关用户问题当成 4320 个独立观测。小矩阵和仅三次重复的计时不足以建立复杂度或统计显著性主张。

可用论文结果表述：在固定参数敏感性实验的 1080 个候选单元中，Q_G 的安全区间下界相对旧共享预算界新增直接认证 10 个单元，可行候选覆盖率从 80.51% 提高到 82.63%，未观测到误接受。筛选加精确回退相对本实验的串行参考实现降低计算成本，但 Q_G 相对旧界的额外认证收益有限，未表现出稳定的额外运行时间优势。
