## 一、被修正的逻辑错误（v1 → v2）

v1 的 `sdp_user_status` 把 **t_cert < −τ 判为 clearly_infeasible**，这不
成立：t_cert 是 q\* 的认证**下界**，负下界不能证明 q\* < 0。v1 报告的
"状态一致率 100%" 是数值精度的巧合（|t−q\*| ≪ |q\*|），不是逻辑正确。

v2 判定规则（每用户双侧界）：

- **L = t_cert**（残差修正后、通过数值有效性检查的下界）：L > τ →
  certified_feasible；
- **U = q(e_witness)**：从修正乘子 λ′ 恢复 (A+λ′I)e = −g（奇异时最小
  二乘），若 ‖e‖ > r **投影到球内**并**重新计算真实目标**（本批
  956/2160 个见证需要投影）；U < −τ → certified_infeasible。U 是可行点
  目标值 = q\* 的合法上界，不宣称 e_witness 最优；
- 其余 → **unresolved**（绝不据此拒绝）。SDP 原始 t 从不用作上界，
  solver status=optimal 不构成不可行判据。

无法恢复可靠见证时应返回 unresolved；本轮批内未发生（见证全部有效，
球残差 ≤ 1e-9 全程）。另设显式命名的 "SDP+TR 完成判定" 管线（TR 调用
单独计数），本轮批内未触发（无 unresolved 用户）。

## 二、残差修正与数值口径的加固

保留平移恒等式 (t,λ)→(t−η(1+r²), λ+η)，M′ = M+blockdiag(ηI,η)，
Weyl 不等式恢复半正定。v2 改动：

1. 前置检查：输入有限性、A 的 Hermitian 对称性（偏差>1e-10·‖A‖ 拒绝）、
   r<0 抛错（不再当 0）、r=0 单独返回名义值；
2. 检查**修正后的** λ′ ≥ 0（v1 只查原始 λ）；
3. 重试循环重构：保存的 η、t_cert、λ′、λmin′ 与**最后一次复核的矩阵
   严格一致**（v1 在重试耗尽时可能不一致）；
4. `psd_margin_achieved` 区分"达到严格正裕量"与"容差内近似半正定"
   （本批 2160/2160 严格正，最小 4.7e-14）；η 中位 3.6e-13、最大
   6.5e-9；
5. 表述口径：这是**经验舍入裕量 + 普通 eigvalsh**，不是形式化误差保
   证；论文用"经残差修正与数值检查的下界"，不称严格数值证书；
6. 有效性不满足 → unresolved_invalid，不静默接受。

## 六、报告与归属口径（按本轮要求收紧）

1. 单球 S-procedure 属**经典方法适配**（引 Zheng et al., IEEE TCOMM
   2025, DOI 10.1109/TCOMM.2024.3516491 作为 RIS 鲁棒设计中的代表性
   用法），不是复现该文算法、不是 2025 新方法；
2. **残差平移修正降级为实现细节**（Weyl 平移 + 经验舍入裕量 + 数值复
   核），未经文献核查不宣称创新；其作用是让内点 SDP 输出可用作认证
   下界；
3. 见证恢复（对偶乘子 → 球内投影 → 真实目标重算）同为工程实现；
4. 实验一致性（双侧界夹逼、与 TR 逐例吻合）是数值证据，**不是解析
   证明**；未宣称区间运算级证书；
5. v1 报告中所有基于旧判定逻辑的结论以本报告为准；v1 数据仅作历史。
