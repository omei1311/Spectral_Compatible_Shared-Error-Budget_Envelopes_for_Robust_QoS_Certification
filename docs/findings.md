## 一、实际计算事实

### A1 方向极值（种子 20261006，30 组随机 + 3 个固定三分支例子）

- 闭式 R 与"4097 网格 + 峰附近有界标量细化 + 端点 s=0,δ,β"参考的
  差：max |R² − ref²| = 3.7e-9（该残差归因于细化优化的收敛容差，非闭式
  误差）；单独保存的纯网格低估量最大 4.1e-5（direction_checks.csv 的
  grid_under 列），两者已区分。
- R ≤ min(β₀√(x²+y²), αx+βy)：3000 次随机抽查最大违反 0.0。
- 分支连续性：在两条内部分界曲线附近 ±1e-6 相对扰动下，
  最大跳变 ≤ 1.0e-6（与扰动尺度一致，支持连续）。
- 手工端点：α=0（β₀=β）、β=0（β₀=α）、x=0、y=0 四种情形
  与解析预期 R=βy / αx 的 |R²−预期²| ≤ 5.6e-17。
- 三个固定例子分别落在分支 1/2/3（(0.2,0.4)→1，(0.4,0.3)→2，
  (0.45,0.1)→3）。

### A2 三分支方向构造（输入维 5、输出维 3，ε∈{1e-2,1e-3,1e-4}）

- 9 个构造全部 bracket 成立（f(0)<0<f(1)，t\*∈(0,1)）；
  六标量复原误差 |α′−α|、|β′−β|、|β₀′−β₀| 全部为机器零（0.0）。
- T−ℓεℓεᴴ 的最小特征值 ≥ 6.1e-8 > 0（PSD 因子 K 存在）。
- ‖x d + y ℓ‖ = R 精确成立；‖x d + y ℓε‖ 与 R 的差（ε 方向亏缺）
  随 ε 线性缩小（如 (0.45,0.1)：4.58e-4 → 4.58e-5 → 4.58e-6）。

### A3 确定性翻转与 Q_G 构造（p=4, a=1.3, I₀=0.5, α=β=1, β₀=1.1,
γ=1, σ²=1.5, r=0.5）

- 一维搜索：x\*=0.49696839, y\*=0.05497657, Q_G=0.03462432。
- A2 补全构造的实例：六标量误差 ≤ 8.9e-16；**精确 q\* = 0.03462432
  与 Q_G 在 8 位有效数字一致（对全部三个 ε）**；构造误差
  e\*=−x\*e₁−y\*e₂ 处目标值与 Q_G 之差随 ε 线性收敛：
  5.1e-4 / 5.2e-5 / 5.2e-6（有限 ε 目标值不必等于 Q_G，符合预期）。
- 确定性翻转矩阵例：实际计算得
  D=−0.042500，旧 Q=−0.024580（参考值 −0.02457），
  新 Q_G=0.034624（参考值 0.03462），
  区间下界 Q_LB(256)=−0.027068 < 0，**Q_G_LB(256)=+0.027262 > 0**，
  精确参考 q\*=0.034624（参考值 ≈0.03462），reference_valid=True。
  与任务给定的诊断值全部吻合（差 ≤1e-5，为舍入）。
  J=65536 时 Q_G_LB=0.033690（仅用于该确定性诊断，未计入任何计时）。

### A4 边界机制短核查（p=2, a=I₀=α=γ=1, β=0.7, σ²=0.05, r=0.2）

- δ∈{0.1,0.03,0.01}：β₀ 复原精确；e=(−0.2,0,0) 处目标值恒为
  **−0.21（三种 δ 完全一致）**；Q_G = q\*（两者相等到舍入）随 δ→0
  趋于 −0.21，同时 ‖h‖ = 20.0 → 66.7 → 200.0 发散。
  即：信息类最优值趋于 −0.21 的同时信道范数发散；这是一族构造实例
  的性质，不能解释为固定物理系统的 QoS 不连续。边界分支（β₀=α）
  与一般分支未混用。
- **未能复现的量**：任务中"β₀=α 时边界包络为 0.59"一句。按给定参数
  （p=2, a=I₀=α=γ=1, β=0.7, σ²=0.05, r=0.2）实际计算的边界分支
  Q_G=−0.21（与 δ→0 族极限和 obj(e) 一致，boundary_checks.csv）。
  0.59 无法由 D、旧 Q、Q_G、Q_G_LB 或 L_quad 在该参数下得出，
  作为未解释差异如实报告，未改动任何数学定义。

### B 21 点谱参数扫描（逐点显式构造矩阵与信道）

- 逐点六标量误差 ≤ 2.2e-16；‖h‖ 沿扫描从 2.22 变到 9.05（族性质，
  已存 CSV）。
- **严格改善**：Q_G > Q_old（容差 1e-9）在 20/21 点成立，
  最大增益 0.0749（β₀=1.1777）；唯一无改善点是 β₀=√2（两端点重合，
  Q_G−Q_old=0）。
- 与真实 q\* 的关系：q\* − Q_G ≥ 0（最小 −1e-15 出现在 β₀=1.2171，
  为一维数值近似的浮点噪声，低于容差，按"近似间隙"处理而非反例）；
  q\* − Q_G_LB ≥ 9.3e-3 > 0 全部成立。
- **认证翻转**：Q_G_LB > τ > 0 且 Q_LB ≤ 0 的点共 6 个，
  β₀∈[1.0791, 1.1777]（这些点 D 也为负或近零；D 全程范围
  −0.397..0.0399）。
- 本族上 L_quad 从不优于 Q_G（Q_G−L_quad ∈ [1.01, 1.14]，因该族
  ‖g‖ 大、L_quad 松）；**但在实验 C 中相反**（见下），故两者无

### C 小型固定 RIS 候选池（720 个用户级球问题，维数 8）

- 720/720 参考全部 reference_valid；180 个候选-半径单元全部
  clearly_feasible（最紧用户 q\* 最小 0.045，min q\*/τ = 4.5e6，
  即所有实例离认证边界都很远）。
- 四种方法（D、旧 Q、Q_G、L_quad）**全部 180/180 直接接受**，
  coverage=1.0，误接受 0，unknown 0；Q_G 相对旧 Q 的新增直接接受
  **0**（Q_G 下界在 720/720 用户问题上都高于旧 Q，但平均增益仅
  4e-4，未跨越任何接受阈值）。
- L_quad 在 635/720 用户问题上比 Q_G 更紧（L_quad 使用六标量之外的
  A,g,c 信息）。两者谁更紧依实例而定，无支配。
- 计时（每种子预热 1 次 + 计时 3 次的中位数 [范围]，秒）：
  界筛选（4 方法，含摘要构建）0.0169–0.0174 [0.0164–0.0194]；
  全精确参考（720 次 TR 求解，含特征分解复用）0.235 [0.230–0.249]；
  筛选+unknown 回退端到端（Q_G 筛选）0.0112–0.0123 [0.0107–0.0142]。
  实际回退调用 0 次（全用户参考评估 720 次与早停串行回退 0 次
  分开统计）。
- 720 个用户级问题来自 60 个候选 × 3 半径 × 4 用户，彼此相关，
  **不是 720 个独立实验**；未做显著性检验。

## 二、异常与限制（如实报告）

1. A4 的"边界包络 0.59"未能复现（上文详述）；其余给定诊断值全部
   复现。
2. 实验C 在固定参数下完全饱和：所有方法接受所有单元，回退机制
   从未触发。因此该池**不能**证明"筛选+回退比全参考净加速"——
   能测到的只是：界评估（含摘要）比 720 次精确参考便宜约一个
   数量级（0.017 s vs 0.235 s/种子）；回退路径的成本在该规模下
   无数据。结论相应收缩。
3. L_quad 与 Q_G 的相对紧度依实例族而定（B 中 Q_G 总是更紧，
   C 中 L_quad 在 88% 用户问题上更紧）。任何"Q_G 支配 L_quad"的
   表述都不被本数据支持。
4. 认证翻转只出现在构造族 B（6/21 点）与 A3 单例；C 中无翻转。
5. 普通 IEEE754 双精度，未做定向舍入，不宣称机器级形式化证书；
   τ=1e-8·scale（C 中 τ 中位数 1e-8、最大 1.9e-8，已记录）。

## 三、能支持 / 不能支持的结论

**能支持（计算事实层面）**：
- 闭式 R 与直接标量极值一致（残差 3.7e-9，纯网格低估单独量级
  4.1e-5）；三分支构造将六标量复原到机器精度且 PSD 残差非负；
- 在全部 900+ 个已算实例（A3、B 21 点、C 720 用户问题）上，
  区间下界不超过精确参考（Q_G_LB ≤ q\*，最小间隙 1.2e-4 > 0），
  且未出现任何误接受；
- 确定性翻转例中，旧 Q 判负而 Q_G 的认证下界为正，与精确 q\*
  一致；
- B 族中 Q_G 对旧 Q 的严格改善区域与翻转点如上（构造族性质）。

**不能支持**：
- 普遍安全性或 sharpness（有限样本不能证明；q\*=Q_G 的等号只在
  构造实例上验证，非定理）；
- "所有场景更优"（C 中接受率并列、L_quad 常更紧）；
- 复杂度优势的定量主张（C 饱和，回退未触发；只有评估成本比较）；
- 文献新颖性（实验无法证明首创）。

## 四、数学事实与文献定位的边界

- 数学定理（R 的三分支表达式、界的安全性、构造的存在性）属于
  证明范畴；本仿真只提供数值核查，不构成证明。
- 本仓库的实验规模与命题严格对应：A 核查数学对象，B 展示构造族
  上的改善区间，C 检验认证接口的成本与安全性；未加入移动轨迹、
  动态刷新、学习算法或联合优化。
